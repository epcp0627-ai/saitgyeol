# 사잇결

**사이트:** https://epcp0627-ai.github.io/saitgyeol/

`main` 브랜치에 변경사항을 올리면 GitHub Actions가 정적 사이트를 자동으로 다시 배포합니다.

취향의 결을 모아 잘 맞을 사이를 그리는 트친소 카드 제작기입니다.

## 주요 기능

- `나 → 취향 → 사이 → 꾸미기`의 4단계 작성 흐름
- 입력과 동시에 바뀌는 편집형 카드 미리보기
- 프로필 사진 확대·위치 조절
- 살구 종이, 비 온 뒤, 초여름, 밤편지 테마
- X 피드 4:3, 세로 4:5, 정사각 1:1 PNG 저장
- 지원 기기에서 이미지 파일 공유
- 브라우저 로컬 자동 저장
- 모바일 하단 작업 바와 키보드 접근성

사진과 입력 내용은 서버로 전송하지 않습니다. 브라우저 안에서 이미지 처리와 PNG 생성을 끝냅니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

배포용 결과물은 다음 명령으로 만듭니다.

```bash
pnpm build
```

GitHub Pages용 정적 결과물은 다음 명령으로 만듭니다.

```bash
pnpm build:pages
```
